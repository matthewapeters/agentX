# AgentX Tools Docs Index

_Last updated: 2026-05-11 (v0.39.3.post1)_

This is the entry point for tool and tooling documentation.

## Documents

| Document | Purpose |
|----------|---------|
| `tools_issues.md` | Active backlog of tool and tooling defects/enhancements (registry, exposure, routing, editor tooling). |

## Scope

- Tool architecture, registration, discovery, and execution contracts.
- Tooling integration with vibe editor and terminal bridge.
- Non-UX operational issues that affect what the agent can do.

## Out of Scope

- GUI interaction bugs and panel behavior defects (tracked in `../ux/UX_ISSUES.md`).
